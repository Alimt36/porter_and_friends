Porter (1980)

Goal

  • Match word forms
  • connect / connected / connecting / connection

Method

  • Suffix stripping
  • Fixed rules, fixed order
  • No dictionary

Output

  • Stem, not a real word
  • happily → happili
  • university → univers

5 steps

  1. Step 1plurals, -ed, -ing, y→i
  2. Step 2long suffix → short (ational→ate)
  3. Step 3-icate, -ful, -ness
  4. Step 4drop -al, -ance, -ment
  5. Step 5final e, double l

Measure m

  • Count of vowel-consonant blocks
  • Rule fires only if the remaining stem is big enough
  • Protects short words

Other algorithms

Lovins 1968

  • First stemmer
  • One pass, longest ending
  • ~300 endings
  • Fast, crude

Lancaster 1990

  • Paice / Husk
  • Rule table, repeated
  • Very aggressive
  • Short stems

Snowball / Porter2 2000s

  • Porter's own upgrade
  • Special words handled
  • Many languages
  • Default choice

Krovetz 1993

  • Dictionary based
  • Inflections only
  • Real words
  • Very gentle

Lemmatization not a stemmer

  • Dictionary + grammar
  • True base word
  • Slower
  • Needs part of speech

NLTK Porter modes

  • ORIGINAL
  • MARTIN_EXTENSIONS
  • NLTK_EXTENSIONS
  • Same algorithm, patched

Takeaways

  • Stemming = recall up
  • Over-stemming = precision down
  • No stemmer is perfect

Caveat

  • Tiny hand-picked lists
  • Illustrates, doesn't prove
  • Real gain: modest for English
